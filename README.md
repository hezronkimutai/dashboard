# Uganda Economic Dashboard

An interactive web dashboard displaying Uganda's economic indicators and growth projections. Built with vanilla HTML, CSS, and JavaScript for maximum accessibility and performance.

## 🚀 Live Demo

**Current Deployment**: https://kenya-economic-dashboard-qk4rcobn0-hezronkimutais-projects.vercel.app

## 📊 Features

- **Interactive Economic Visualizations**: 6 dynamic charts showing GDP, per capita income, growth rates, and progress metrics
- **Real-time Calculations**: Instant updates to all visualizations when economic parameters change
- **Scenario Planning**: Adjust GDP and population growth rates to explore different economic scenarios
- **Mobile Responsive**: Professional Material Design interface that works on all devices
- **Zero Dependencies**: Pure HTML/CSS/JS with Chart.js for visualizations

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Charts**: Chart.js for interactive visualizations
- **Styling**: Material Design-inspired dark theme
- **Deployment**: Vercel static hosting

## 📈 Economic Indicators

- **GDP Growth Projection**: Historical and projected GDP trends
- **GDP Per Capita**: Individual economic progress tracking
- **Growth Rate Analysis**: GDP and population growth rate visualizations
- **Middle Income Progress**: Progress toward lower middle-income classification
- **Time to Target**: Projected years to reach economic development goals

## 🏃‍♂️ Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/256-io/dashboard.git
   cd dashboard
   ```

2. Open in browser:
   ```bash
   # Simply open index.html in any modern web browser
   open index.html
   # Or serve locally (optional)
   python -m http.server 8000
   ```

3. Start exploring Uganda's economic data!
