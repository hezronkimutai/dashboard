# Project Brief - Uganda Economic Dashboard

## Core Project Identity
**Name**: Uganda Economic Dashboard  
**Repository**: dashboard  
**Organization**: 256-io  
**Live URL**: https://256-io.github.io/dashboard/

## Mission Statement
Create an open source dashboard that displays economic data for Uganda, providing accessible visualization of key economic indicators.

## Primary Goals
1. **Data Visualization**: Present Uganda's economic metrics in an intuitive, visual format
2. **Open Source**: Build a community-driven project that welcomes contributions
3. **Accessibility**: Make economic data understandable and accessible to various audiences
4. **Real-time Insights**: Provide current economic indicators and projections

## Key Economic Metrics Tracked
- **GDP**: Total GDP value and growth rates
- **Population**: Population size and growth trends  
- **Per Capita Income**: Individual economic indicators
- **Growth Projections**: Economic growth forecasting
- **Middle Income Goals**: Progress toward middle-income status targets

## Target Audience
- Policy makers and government officials
- Economic researchers and analysts
- Citizens interested in Uganda's economic progress
- International development organizations
- Open source contributors

## Success Criteria
- Clear, accurate visualization of Uganda's economic data
- Active community contribution and engagement
- Reliable deployment and accessibility
- Educational value for understanding economic trends

## Open Source Philosophy
The project actively encourages contributions from the community, as evidenced by:
- Public GitHub repository
- Contribution guidelines
- Code of conduct
- Open source licensing

This dashboard serves as both a practical tool for economic analysis and a platform for collaborative development in the Ugandan tech ecosystem.
